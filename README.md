# Mohamed Etaib Benaicha — Portfolio

A responsive personal portfolio built with React + Vite, styled with a dark navy and electric-blue visual system.

## Requirements
- Node.js 18+ (Node.js 20 LTS recommended)
- npm

## Run locally on Windows
1. Extract the ZIP file.
2. Open the `mohamed-etaib-portfolio` folder in VS Code.
3. Open a terminal in that folder.
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```
6. Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Production build
```bash
npm run build
npm run preview
```

## Customize before publishing
- Replace the placeholder email in `src/App.jsx`.
- Add your actual CV as `public/Mohamed-Etaib-Benaicha-CV.pdf` (the download button points to this filename).
- Add project repository/demo links where available. The UI deliberately marks unavailable links as not yet added rather than inventing URLs.
- Review project status and descriptions so they accurately reflect what is implemented vs. explored.
- Replace the sample profile initials/avatar with a real portrait if desired.

## Deploy
You can deploy the repository to Vercel or Netlify. Use the default Vite build command `npm run build` and output directory `dist`.
